Nothing super remarkable here, just my custom Vivaldi theme (updated to version 8.0 with unified themes) to match the colors and stylings of the Linux Mint Mint-Y-Dark-Teal system theme.

Download the Mint-Y-Dark-Teal.zip file from the repository.

In Vivaldi go Settings -> Themes, click on Import Theme, and upload the file.

There's no need to extract the files.  Vivaldi will do all the work for you.
